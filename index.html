บันทึก / โหลด

บันทึกเป็นไฟล์ JSON เพื่อเก็บทุก Layer รูปทรง และการตั้งค่าไว้เปิดต่อภายหลัง

Layers

คลิกเลือก Layer เพื่อวาดแยกชั้น เปิด/ปิดตาเพื่อซ่อนหรือแสดง และใช้ปุ่ม ↑ ↓ เปลี่ยนลำดับชั้น (ชั้นบนจะวาดทับชั้นล่าง)

พิกัดเริ่มจากมุมซ้ายบน (0, 0) แบบเดียวกับ Tkinter Canvas: x เพิ่มไปทางขวา และ y เพิ่มลงล่าง
เครื่องมือ Pen / Polygon: คลิกเพื่อสร้างมุม หรือคลิกค้างแล้วลากเพื่อสร้างเส้นโค้ง; ใช้ Add Anchor Point คลิกใกล้เส้นขอบ Polygon เพื่อเพิ่มจุดยึด และเปลี่ยนสีรูปที่เลือกได้จากช่องสี Fill/Outline
ทำให้เส้นโค้งแบบ Photoshop: (1) โหมดเลือก — ลากที่ตัวเส้น (เส้นตรงหรือเส้นโค้งก็ได้) เพื่อดึงให้โค้ง (2) ลากที่ handle เพื่อปรับความโค้ง จุดที่เป็น smooth จะหมุน handle อีกข้างตามอัตโนมัติ (กด Alt ค้างเพื่อแยกอิสระ) (3) เครื่องมือ “แปลงจุด” — ลากจากจุดยึดเพื่อดึง handle ออกมา หรือคลิกที่จุดเพื่อเปลี่ยนกลับเป็นมุมแหลม

แก้โค้ดในช่องนี้แล้วกราฟจะอัปเดตอัตโนมัติเมื่อมีคำสั่งที่อ่านได้; รูปที่แก้จะถูกแทนที่ใน Layer ที่เลือก. การหมุนจะแปลงรูปสี่เหลี่ยม/วงรีเป็น Polygon เพื่อรักษามุมหมุน. พิกัดเป็นพิกัด Canvas และโค้ดที่คัดลอกจะรวมรูปทั้งหมดที่มองเห็น
